# Habit Dashboard

Dashboard estático e responsivo para acompanhar hábitos diários. Funciona sem servidor, sem dependências e mantém os dados no `localStorage` do navegador.

## Executar

Abra `index.html` no navegador. Para desenvolvimento, também pode usar a extensão Live Server do VS Code.

## Recursos

- Criação de novos hábitos com validação básica.
- Marcação diária e sequência de dias consecutivos.
- Indicador de progresso do dia.
- Preferência de tema escuro salva no navegador.
- Navegação por teclado, contraste e mensagens para leitores de tela.

## Ideias para evolução

Exportar dados em CSV, autenticar usuários e sincronizar hábitos com uma API.
